# WIZio-RTU MQTT Device
Welcome to the WIZio-RTU MQTT device.

To start your journey, upload all files except tools/ folder to your device.

Rename file `mqtt.default.json` to `mqtt.json` and enter information about your MQTT Broker's information.

The tools/ folder contains dashboard.py, which you can use to view and control the device's peripherals.<br> 
See the README file in the folder for more details.

Once the upload is complete, reset the device to start the MQTT client program.

If you found any Syntax Error when uploading these files, try reuploading given file and reset your device.
`main.py` should automatically run afterwards.

Visit [WIZio-RTU MQTT documentation](https://docs.w5500.com/reference/wiz-rtu.html#mqtt-device) for detailed guide.
